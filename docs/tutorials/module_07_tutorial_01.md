# Tutorial 01: Your First Contract Synthesis

**Difficulty**: Beginner  
**Duration**: 10 minutes  
**Prerequisites**: Basic Python knowledge

## Learning Objectives

By the end of this tutorial, you will:
- Understand what contract synthesis does
- Load an IR artifact from a file
- Synthesize your first FFI contract
- Examine generated clauses and metadata

## Introduction

The Contract Synthesis Engine (Module 07) transforms structural facts from Intermediate Representation (IR) artifacts into enforceable FFI contracts. Think of it as an automated reasoning layer that takes "what the interface looks like" (layout, types) and derives "what must be true at runtime" (invariants, nullability, ownership).

## Step 1: Preparation

Ensure the project is set up or you are within the project workspace. Module 07 depends on Module 05 (IR) and Module 06 (Contract Schema).

## Step 2: Create a Sample IR File

Create a file named `sample_interface.json`:

```json
{
  "target_architecture": "x86_64",
  "operating_system": "linux",
  "pointer_width": 64,
  "endianness": "little",
  "abi_mode": "sysv",
  "compiler_family": "gcc",
  "compiler_version": "11.0.0",
  "entity_id": "tutorial_unit",
  "kind": "interface_unit",
  "symbols": [
    {
      "linkage_name": "process_data",
      "source_name": "process_data",
      "entity_id": "fn_process",
      "kind": "function_symbol",
      "calling_convention": "cdecl",
      "parameters": [
        {
          "parameter_index": 0,
          "parameter_name": "data",
          "type_reference": "void*",
          "entity_id": "p0",
          "kind": "parameter"
        }
      ]
    }
  ],
  "types": [
    { "entity_id": "void*", "kind": "pointer_type", "pointer_depth": 1 }
  ]
}
```

## Step 3: Write the Synthesis Script

Create a script named `synthesize_test.py`:

```python
from module_07_contract_synthesis import synthesize_from_ir

# Synthesize contract with a single function call
print("Synthesizing contract...")
contract = synthesize_from_ir('sample_interface.json')

# Print summary
print(f"Interface: {contract.header.target_interface_id}")
print(f"Total Clauses: {len(contract.clauses)}")

# Breakdown of clauses
for clause in contract.clauses:
    print(f"  [{clause.clause_type.value}] ID: {clause.clause_id}")
```

## Step 4: Run and Analyze

Run the script:

```bash
python synthesize_test.py
```

### Understanding the Results

In the output, you should see several clauses generated automatically:
1. **Calling Convention**: Ensuring the function is called with `cdecl`.
2. **Nullability**: By default, the `void*` pointer is assumed non-null for safety.
3. **ABI Compatibility**: Minimal environment requirements for the interface.

## Step 5: Explore Provenance

Each clause contains "provenance" metadata so you know exactly why it was generated.

```python
# Print provenance for the first clause
if contract.clauses:
    clause = contract.clauses[0]
    prov = clause.metadata.get('provenance', {})
    print(f"\nClause: {clause.clause_id}")
    print(f"  Generated by rule: {prov.get('rule_id')}")
    print(f"  Confidence: {prov.get('confidence')}")
```
