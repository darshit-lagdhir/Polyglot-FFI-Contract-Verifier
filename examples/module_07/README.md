# Module 07: Contract Synthesis Engine - Examples

This directory contains practical examples demonstrating Module 07 usage.

## Example Categories

### Basic Examples
- `01_simple_synthesis.py` - Basic contract synthesis
- `02_configuration.py` - Customizing synthesis

### Advanced Examples
- `10_performance_optimization.py` - Performance tuning (caching and profiling)

## Running Examples

Each example is self-contained and can be run directly:

```bash
cd examples/module_07
python 01_simple_synthesis.py
```

## Prerequisites

- Module 07 installed: `pip install module-07-contract-synthesis` (or available in python path)
- Sample data files (provided in `data/` directory)

## Example Data

Sample IR files are provided in the `data/` directory:
- `simple_interface.json` - Small test interface
