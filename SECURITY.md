# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please:

1. **Do NOT** open a public issue
2. Email `security@pfcv.dev` with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will respond within 48 hours and work with you to address the issue.

## Security Best Practices

When using Module 07:

1. **Validate Input**: Always validate IR artifacts from untrusted sources
2. **Use Strict Mode**: Enable strict validation in production
3. **Keep Updated**: Use the latest version
4. **Monitor Dependencies**: Keep dependencies updated

## Known Issues

None at this time.

## Disclosure Policy

- We will acknowledge receipt within 48 hours
- We will provide an estimated timeline for a fix
- We will credit reporters (if desired) in release notes
- We will coordinate disclosure timing
